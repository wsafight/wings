# ADR-0001：VM 的边界与命名

- 日期：2026-11-12
- 状态：已采纳（设计）；名称约定由 [ADR-0008](0008-wings-naming.md) 补充

## 背景

Wings 是独立运行的微进程虚拟机，需要明确执行引擎、编译工具与编辑器服务的职责。

## 决定

- 执行引擎命名为 `wings-vm`，负责装载、微进程、GC、调度、消息与监督，包内同时提供库和薄的 VM 命令行入口。
- 库用于测试和内部组织，首版不承诺稳定嵌入式 SDK。VM 用 Rust 实现，不要求用户编写 Rust 宿主。
- 编译工具叫 `wings-compile`，语言服务器叫 `wings-lsp`；`wings-lang` 仅作为业务语言名称。

## 替代方案

- 单独设置 VM 命令包装包：目前入口只需处理参数、日志和退出状态，先放在执行引擎包中。
- 所有编译和执行代码都放入 `wings-vm`：会让执行程序与编辑器工具引入不需要的后端依赖，不采用。

## 影响

项目名为 Wings VM，执行、编译与编辑器工具分别命名。名称尚未完成包名占用或商标核查。

## 重审条件

当命令入口出现独立的发布、测试或依赖隔离需求时，再评估是否单独拆包。
