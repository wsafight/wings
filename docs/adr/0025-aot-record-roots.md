# ADR-0025：AOT 临时记录与编译器根发布

- 日期：2026-11-12
- 状态：已采纳（M0 内部 IR 集成切片）
- 补充：[ADR-0004](0004-safepoints-and-gc.md)、[ADR-0018](0018-bounded-record-heap.md)
- 替代：[ADR-0024](0024-scalar-stack-boundary.md) 的 v4 context 布局；保留栈准入与正常返回契约
- 后续：[ADR-0026](0026-language-temporary-records.md) 将临时记录接入源码与显式 worker/CLI 堆，修正同步堆实例的同账户栈计费；ABI v5 不变。

## 背景

独立记录堆只能验证宿主手动根，标量活栈不能验证编译器是否发布全部引用。先将有限记录接入内部 IR 和真实 AOT，不同时扩展语言、消息 codec 或持久业务状态。

## 决定

- 未发布源码升级 ABI v5，context 追加 shadow frame 链头、可空堆内建回调及独立 heap data 指针。frame 为 C 布局的 previous、连续 u64 根槽指针和 count；槽内是当前进程堆的 slot/generation 编码，不是 native 指针。增加堆满及无效根状态码，旧 v1–v4 清单在装载库前拒绝。
- 内部 IR 增加 `Ref` 类型与 `RecordInt`、`ReadInt`、`Collect` 三种操作，仅创建单字段 Int 不可变记录。Ref 不能来自常量、算术、状态或参数，也不能作为状态、消息或回复类型；清单显式拒绝 Ref。业务语言不增加记录语法。
- 编译器计算直线 SSA 引用的最后使用位置，在每个强制检查点和堆内建调用前，将当时仍活跃的引用紧凑写入栈内 shadow slots；不发布整数或已死亡引用。分配结果到下一 safepoint 前不触发其他 GC。每函数至多 64 个同时存活引用，超限在写产物前拒绝；总操作数仍有界。
- 有引用的业务帧进入时链接 shadow frame，所有成功、算术失败、预算、取消或内建失败路径统一解链后正常返回。暂停保留根槽及链头，恢复仍检查同一上下文，不重放指令。薄入口继续在业务帧分配前检查剩余栈；标量函数不分配 shadow frame。
- VM 的 `instantiate_with_heap` opt-in 初始化接口为实例建立进程计费的固定记录堆，initializer 也可使用临时记录。堆控制块与根表先预留再 fallible 分配；实例只持有可选独占指针，调用时移入协程，返回后归还，没有跨线程共享或指向可移动实例的自引用。worker 默认仍为无堆的标量实例，不开放语言堆。堆容量计费不含 allocator 内部开销，`heap_stats` 只报告底层记录堆而非根表/控制块总额。
- 堆内建只在本执行线程访问 heap data；先验证整条根链及 handle，再进行精确、非移动 mark-sweep。最多 64 帧、合计 64 根，越界或无效根先失败且不回收。显式 Collect 立即收集；分配失败先尝试从发布根回收一次，再返回堆满。根与工作表不在 GC 中动态分配，容量在构造前三级准入。
- shadow frame/slots 必须是可信生成代码当前活栈内的有效对齐存储；链与计数检查不能把任意 native 指针变安全。本地 Ref 编码只在本堆解释，不能用于跨堆传递或安全反序列化。装载仍为 unsafe 可信本机边界，内存破坏不承诺局部恢复。

## 验证与边界

Rust 测试覆盖 IR 类型/边界与活跃度、清单拒绝 Ref、ABI 布局、完整根链验证、无效根零回收、堆构造准入及退出清理。受限 OS 子进程以实际 AOT 验证跨 safepoint/暂停保活、死引用释放与槽位复用、整数位型不误认根、满堆失败、取消/预算/算术失败解链和重复调用，不在宿主注入真实 OOM 或非法指针。

debug/release、macOS AArch64 和 Linux x86-64 分别验证，新增栈帧仍受 64 KiB 静态准入。未实现语言堆、持久状态/消息/回复根、业务函数调用、循环、M:N 或完整 GC 延迟证明，不能宣布 M0/MVP 完成。暂停期间的根链保留由回归验证，但本切片不提供宿主在暂停期间任意 GC 的接口。

## 替代方案与重审条件

- 继续只测 Rust 手动根：不能发现代码生成遗漏。
- 先开放任意引用状态与消息：同时引入跨调用/跨进程所有权，难以定位根遗漏。
- 保守扫描原生栈或保留全部历史引用：前者违反精确根，后者可能隐藏死对象无法回收的错误。

引入多字段记录、引用状态、语言语法或业务调用时须重新设计布局、全部根来源及容量计费；开放更大堆前测量最大 GC 不可抢占区段。不将本原型或单项微基准描述为领先 BEAM。
