# ADR-0031：标量状态循环与回边检查

- 状态：已采纳（M0 回边执行切片）
- 补充：[ADR-0029](0029-scalar-conditional-expressions.md)、[ADR-0030](0030-scalar-comparisons.md)

## 背景与决定

无回边入口不能验证长 handler 的持续抢占。先开放以唯一标量 state 为循环携带值的 while，不引入可变局部、递归或引用状态 phi。

- handler 内可写 `while condition { statements }`，条件必须 Bool，循环体结果必须 Unit；只有 state 可赋值，let 仍不可变。循环可嵌套，体内局部只在该体内可见，不遮蔽外层名字。state 类型限 Int/Bool/Unit，RecordInt 状态暂拒绝循环；外层或体内仍可使用临时记录内建。无 break、continue、return 或阻塞等待。
- 每次迭代重新计算条件；假则继续后续语句，真则执行一次循环体并带候选状态回边。handler 正常返回前不提交任何迭代；取消、预算或算术/堆失败不提交候选、不成功回复。不承诺循环终止，执行总预算始终有效。
- IR 采用配对 Loop/While/EndLoop 标记，状态 header/exit 使用标量块参数。控制区域与 if 必须正确嵌套，最多 64 层；校验状态类型、条件、回边值与寄存器作用域。条件/体内部寄存器不能逃逸到循环外。
- 每个实际执行操作、Loop header、While 条件分派和 EndLoop 回边保留强制取消/预算/让出检查；空循环也不能绕过。假条件不执行体或回边标记，后续操作/最终提交另有检查。只恢复原栈和当前迭代，不重放已执行指令。
- 外层 Ref 若在循环条件或体使用，其最后使用至少延长至该循环回边，嵌套区域由内到外计算；循环内 Ref 不允许跨迭代携带或逃逸。根发布可暂时多保活外层值，但不得发布未执行分支/迭代的局部引用。每函数 64 根及固定堆/栈限额不变，GC 仍有界且不在后台运行。
- ABI v6 不变；解析器块递归和 IR 控制嵌套均设 64 层上限，源码/表达式/4096 操作等原有限额继续有效。该限制不是最终语言表达力。

## 验证与边界

前端/LSP/IR 验证条件/状态/体类型、嵌套、作用域、畸形输入、深度及控制配对；原生受限子进程验证零次/多次/嵌套迭代、候选提交、算术/预算/取消失败、空循环预算、逐片恢复、外层/局部记录 GC、双 actor 轮转与计时让出。debug/release、MSRV、双平台独立执行。

不开放引用 phi 或任意 CFG，不取消检查换取吞吐；无 M:N 或公平性/BEAM 性能达标结论。后续业务函数、引用携带值和分块 runtime 长操作须另立根/栈与失败证明。
