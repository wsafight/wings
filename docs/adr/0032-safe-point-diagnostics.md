# ADR-0032：单 worker 安全点诊断快照

- 日期：2026-11-13
- 状态：已采纳（M0 宿主诊断切片）
- 补充：[ADR-0015](0015-owned-scalar-tasks.md)、[ADR-0020](0020-single-worker-mailbox.md)、[ADR-0025](0025-aot-record-roots.md)

## 背景与决定

活栈执行期间，堆由协程独占；只查询进程外壳不能获得 GC 和预算进度。不能为诊断保存悬挂 context 指针、跨线程访问 actor，或恢复执行来获得“实时”数据。

- 执行入口开始前记录总预算和初始堆统计。每次实际让出时，协程按值返回剩余预算和堆统计；正常或失败返回后从归还的堆更新快照。`ScalarExecution` 与 `ScalarTask` 暴露只读 `ExecutionSnapshot`，task 保留最近一次入口的结果，后续成功 start 才替换。零步 resume 等宿主参数错误不改变快照。
- worker 的 `snapshot` 汇总 Idle/Runnable/Suspended、排队数/容量、当前 handler 名、state 类型、最近入口进度、堆统计与进程账户用量。只有标量已提交状态可见；RecordInt 状态只显示类型，不暴露 handle 或候选状态。supervisor 转发相同查询；已退出、过期和其他 worker 的 Pid 均拒绝。
- 所有数据只在 worker 所属线程、入口开始/让出/返回这些所有权边界复制。让出回调读取堆时不得有未结束的堆操作借用；生成代码在独立内建调用返回后进入 safepoint。快照不携带 context、根链、堆指针或引用业务值。handler 名借用现有模块，不分配诊断字符串。
- 查询不执行程序、不触发 GC、不推进 deadline 或消耗预算。Suspended 的执行/堆数据是最近安全点，不是后台实时采样；Idle 的堆数据来自归还的堆。`allocated` 表示尚未回收的槽，不表示当前存活业务量。计数是单个入口/堆的统计，不冒充全实例累计指标。
- 快照为固定大小值，不增加可增长容器。actor 中增加的缓存按既有 `size_of` 路径计费；让出时的堆统计扫描至多 1024 槽，不在每个普通 poll 上扫描。扩大堆或优化统计方式必须重测不可抢占区段及统计一致性。

## 验证与边界

不采用 context 裸指针采样或共享堆借用：它们会引入悬挂指针或破坏协程独占。暂不增加后台采样线程、动态历史队列或每个 poll 的指标累加；后续 M:N、分块 GC 或扩大堆容量时重审快照边界和最坏扫描成本。

Rust 回归覆盖入口未开始、逐片让出、完成、取消、预算失败、非法 resume、排队/提交/退出、无堆及引用状态隐藏和查询不改变计费。真实 AOT 循环回归验证预算单调、GC 计数和快照重复读取不改变执行及计费。执行 debug/release、MSRV 和双平台检查。

ABI v6、`ExecutionStatus` 与调度语义不变；本切片不提供跨线程观测、故障历史存储、语言诊断消息、堆遍历或性能达标结论，不替代完整 MVP 可诊断性验收。
