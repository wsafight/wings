# ADR-0033：RecordInt 条件合流与路径根

- 日期：2026-11-13
- 状态：已采纳（M0 引用控制流切片）
- 替代：[ADR-0029](0029-scalar-conditional-expressions.md) 的“条件结果限标量”与对应直线根计划限制；其余语法、惰性求值与预算契约保留。

## 决定与理由

持久记录状态需要按条件选择新记录或旧状态。把两臂都算出来再选择会改变副作用/失败顺序；只删除类型限制则会在合流检查点发布未执行臂的引用。

- `if Bool { expression } else { expression }` 两臂可同为 RecordInt。仍只执行选中臂，只允许单表达式，不允许臂内赋值/语句；消息参数/回复仍限标量。记录结果可用于局部、state 初始化或候选替换、嵌套条件及标量 state 循环体，不开放引用循环携带值。
- 每个条件保存进入时的外层根集合。生成 else 路径时恢复该集合；合流时丢弃两臂局部根，只保留合流后仍活跃的外层根和该路径传入的结果。不能发布另一臂的寄存器或已不再支配当前块的定义。
- Ref 合流使用 i64 编码块参数，但其语义仍是当前进程堆的引用，不允许整数转换或跨堆传递。合流块必须先取得块参数并发布结果根，再执行该 EndIf 的取消/预算/让出检查，避免引用在进入合流安全点时短暂失根。死结果无需保活。
- 根槽容量按相同路径恢复规则计算，不叠加互斥分支的局部值；外层活跃度仍保守使用最后使用位置，循环外层根延长规则不变。64 根、64 控制层、4096 操作、固定栈/堆与最终提交检查继续生效。
- ABI v6 与旧产物不变；运行时根链读取协议不变。不增加 runtime 类型标签或新的引用来源认证。失败不替换已提交状态，独立持久根保活旧状态。

## 验证与重审

前端/LSP/lower/IR 覆盖同类型与错误类型、嵌套、跨臂/合流局部逃逸和根上限。真实 AOT 在每个慢路径和内建前强制 GC，分别走两臂、嵌套、死结果、别名、循环体和持久 state；验证单步恢复、失败/取消/预算不提交、计费归还和两槽堆反复替换。debug/release、MSRV 及两个首要平台独立验证。

不使用 eager select 或关闭合流 safepoint。不把根计划称为一般 CFG 数据流分析；开放引用循环/业务函数、多值合流或移动 GC 时须另立证明。本切片不完成 M0 或 MVP，没有 BEAM 性能结论。
