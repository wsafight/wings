# ADR-0042：有界受管函数帧与跨帧精确根

- 日期：2026-11-13
- 状态：已采纳（M0 调用栈切片）
- 替代：[ADR-0036](0036-bounded-inline-functions.md) 的完全内联后端；保留其源码函数边界

## 决定与理由

将 process 内 fn 编译为私有受管函数及薄入口，不再展开函数体。重复调用不复制 IR；仍禁止递归、前向调用、函数值、函数内 while/state 访问和消息副作用，不开放不受约束的原生调用。

- 实参从左到右各求值一次，写入调用者固定栈槽。内部调用沿用 ABI v10 的四参数与状态码协议，隐藏 state 为 Unit，结果经 ScalarOutput.reply 返回；私有符号不进入产物清单，不供宿主调用。
- 每个函数薄入口在分配业务帧前检查实际剩余 guarded stack，使用后端实际帧大小及既有可信慢路径余量；不足返回 StackExhausted。每次操作及最终返回仍执行强制预算/取消/让出检查，即使函数仅返回参数也消耗预算。嵌套挂起保留全部真实调用帧，取消正常逐层返回，不跨 ABI unwind。
- caller 在调用前发布实参及继续执行所需精确根，callee 将自己的 shadow frame 链到 caller。所有成功/失败返回均恢复 previous；返回引用在下一检查点前由 caller 接管，不在无根窗口执行 GC。已提交状态仍由宿主根持有，失败不提交候选状态。
- 最多 64 个函数、每函数 64 参数、最长静态调用链 32 层，每函数/入口最多 4096 操作；所有函数、initializer 和 handler 的总 IR 最多 65536 操作。表达式深度仍为 256，但不跨函数展开累加。
- 按声明顺序验证有向无环调用图，拒绝未知/前向目标及参数/结果不匹配。每条路径以 caller 最大根容量加最大 callee 路径容量保守准入，合计不超过 64；不在执行时分配增长的根表。该上界可能拒绝本可运行的程序，后续只在证明后放宽。
- 不改变外部 ABI v10 布局或消息/请求契约，无新依赖。LSP 和语义检查保持前端独立；VM 不引入 compiler/codegen 依赖。

## 验证与重审

IR 检查目标、签名、作用域、循环/副作用边界、深度、总操作数与聚合根上界。受限 OS 子进程覆盖参数求值顺序、嵌套标量/记录/列表返回、caller 活根在 callee collect/分配/慢路径时保活、每层 previous 恢复、逐步挂起及取消、候选状态失败不提交、剩余栈不足和计费清理。debug/release、MSRV 与两首要平台独立验证，历史原型 CI 不代替新代码验证。

这是非递归调用栈切片，不等于完整 M0 或 MVP。递归、动态派发、引用消息、分块 GC/runtime 长操作、M:N、外部 I/O 与双平台同负载 BEAM 吞吐/内存门禁仍须分别完成。递归或变更调用约定前须另立 ADR 和栈/根预算证明。
