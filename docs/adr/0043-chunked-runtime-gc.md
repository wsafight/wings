# ADR-0043：分块 GC 的预算、让出与取消

- 日期：2026-11-13
- 状态：已采纳（M0 runtime 长操作切片）
- 补充：[ADR-0004](0004-safepoints-and-gc.md)、[ADR-0042](0042-managed-function-frames.md)

## 决定与理由

保留非移动精确 mark-sweep 与每堆最多 1024 个节点，将受管路径的完整 GC 拆为可暂停的固定工作块；不在一次 native 调用中无检查地遍历整个堆。

- roots 最多 64 个 compiler 根加 1 个已提交状态，先完整验证并复制到既有计费根表。然后依次清除旧标记、标记根、遍历传递边、清扫；每块最多 16 个节点/根，每节点最多 8 个字段。
- 每个工作块前执行原子取消/让出及总预算/时间片检查，扣一个 runtime 工作单位。时间片耗尽经既有慢路径暂停原栈，恢复继续原 phase/cursor/worklist，不重做已处理块。总预算与取消失败逐层正常返回，不改 ABI v10，不提交候选 state 或自动回复。
- 先完成所有标记才清扫，暂停时 actor 不执行其他入口，其他 actor 不访问该堆。取消在标记期不回收对象；取消在清扫期可已回收无根对象，仍保留所有活根。下一轮总是先清旧标记，不要求取消时一次清空全堆；显式宿主 GC 同样使用该核心但同步跑完。
- 准入后的固定 worklist 复用，collection phase/cursor 是 coroutine 栈上固定小结构，无额外增长分配。已分配/退役计数随节点变更维护，使安全点 heap_stats 不再全堆扫描。
- 分配空位查找也按 16 槽分块检查，但不额外扣新步数，避免小堆行为变化；GC 工作块消耗预算。输入仍有 1024 槽上限，不宣称所有 runtime/模块/allocator 长操作均已完成。
- 进入慢路径前结束对 heap 的 Rust 可变借用，保证诊断读取或调度其他 actor 时不保留重叠访问。仅同线程原栈恢复，无迁移或并发 GC。可信宿主 callback 不得重入同一 actor/heap。

## 验证与重审

core 验证逐 phase 单块上界、传递保活、部分标记/清扫中止后再收集、stale handle 与计数守恒。真实 AOT 受限子进程验证大堆 explicit/分配触发 GC 的多次暂停、跨帧根、总预算/取消/Drop、有限 mailbox 轮转与清理。debug/release、MSRV 及两首要平台独立验证。

该切片不是增量并发 collector，也不承诺单个块的硬实时上限。扩大节点/字段/根限额、并发访问、修改消息根或移动性前重审。完整 M0、M:N、I/O、通用业务值和双平台 BEAM 吞吐/内存门禁仍未完成。
