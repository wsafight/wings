# ADR-0092：双发送者的失败前缀对照

- 日期：2026-11-14
- 状态：已采纳（并发失败正确性切片，不是性能验收）
- 依据：[ADR-0065](0065-two-sender-counter-fifo.md)、[ADR-0074](0074-bounded-concurrent-recovery.md)
- 后续：[ADR-0120](0120-persistent-concurrent-failure-soak.md) 复用本业务核心增加独立持续环境与槽复用验证，原 v9 协议/短测限额不变；不等同完整长时故障或恢复门禁。

## 决定与边界

v3 只验证两个真实发送者的成功交错，v2 只用一个发送者注入失败，ADR-0074 则没有 BEAM 对照。增加独立 v9，把两发送者、同目标竞争、候选状态失败、旧提交值和独立目标推进放进同一个有界业务。v1–v8 不改，ABI v15、语言类型拼写和运行时语义不变。

两个真实宿主线程或 BEAM 进程从开始闸门直接投递，各自窗口 16、流长至多 128，总计至多 256 请求。1..100 actor、每 actor mailbox 32，完整状态仍为 256/4096/65536 B：counter、actor ID、两个发送者的已提交目标序号各 64 bit，其余为零。每目标每发送者从 1 连续编号，checked 加法先构造候选 counter/序号，再按显式 fail 标志触发受管失败；候选和回复均不提交。输入只允许所有交错都不会算术溢出的 delta 集合，因而业务失败唯一是显式注入。序号错误使用不同故障分类，不能冒充注入失败。

BEAM 复用 ADR-0067 的发送前 CAS gate，容量固定 32，开始处理时归还排队槽，失败前关闭 gate。两 sender 窗口合计至多 32，不允许 `mailbox_full`；若发生仍判为验证失败。gate 的 `closed` 与已观察到 DOWN 都可拒绝后续投递，不用无界 mailbox 代替有限准入；全部 actor 结束后 gate 必须保持关闭。

每条输入恰有一个结果：已接受的成功回复 `reply`、已接受但目标失败的 `failed`，或投递前已观察到目标关闭的 `closed`。拒绝不重试；两个运行时无需在同一位置观察关闭。每个接受票据只消费一次，所有排队请求在失败或清理后终结。无结果超时、取消、重启或自动重发，不能将此切片称为完整超时/恢复或长时故障门禁；这些仍按 ADR-0074 和路线图独立验收。

Wings 使用每 child 的有界监督终态，不依赖可覆盖的 `last_exit`。失败终态在 actor 清理后交接，携带旧提交 Bytes 的长度和 32 B 前缀；BEAM 用 parent 和两个发送者各自的 monitor，保留实际回复先于 DOWN 的次序。主驱动收齐发送者和所有 actor 的终态后报告每目标 counter、两个提交序号、失败原因和逐输入结果。健康目标完成全部输入；失败目标只承认失败前的提交前缀。停止全部 actor 并释放模块/tenant/控制对象后，Wings 必须回到非零计费根基线。

独立 Python 按目标取两条输入流，验证各发送者成功结果形成连续前缀、前缀没有 fail、每条实际回复值存在合法 FIFO 交错、最终 counter/序号恰好对应该前缀。失败目标的下一条必须存在一个已接受的 fail 请求，禁止凭空故障、失败后提交、候选值泄漏或把拒绝当执行。两端的交错、成功数和关闭位置可以不同，不能直接比较整份 JSON。

沿用原业务 CPU 5 秒/墙钟 10 秒/core 0、每配置一个总 3 秒阶段，以及完整 AOT 的 CPU 20 秒/墙钟 30 秒限制。输入 64 KiB、输出 1 MiB，Wings VM/tenant 256 MiB、process 4 MiB、2 worker、32 共享结果槽；BEAM 固定 2 scheduler、每业务进程有限 heap。显式 `--compare-beam` 才运行 OTP 29，缺少时失败，不回退。

## 验证与重审

三种完整状态分别覆盖空流、单/双发送者注入、同目标双方竞争失败、健康 sibling、跨窗口关闭、100 目标与 i64 边界。独立枚举小流交错生成模型正例，另拒绝伪造回复、跳号、假失败、错误提交前缀、重复/缺失结果及类型/输入边界。真实 AOT 另确认错误序号与注入失败的故障区分；debug/release、完整 AOT、显式 BEAM 和 Linux 隔离执行均保留原限制与失败记录。

只比较最终加法无法发现失败后的提交，只跑单 sender 又无法覆盖交错前缀，故保留逐请求结果和独立前缀模型。引入取消、期限、恢复或引用回复时，应另行定义对应可观察结果和模型，不把未执行的工作算作本片完成。
