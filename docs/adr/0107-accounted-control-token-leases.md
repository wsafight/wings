# ADR-0107：可共享控制标志的计费租约

- 日期：2026-11-17
- 状态：已采纳（资源账本切片）
- 延续：[ADR-0080](0080-central-execution-admission.md) 的调用控制准入与 [ADR-0071](0071-observed-atomic-yield.md) 的观测租约。

## 背景与决定

执行核心的 4352 B 预留覆盖本次调用创建的控制对象，但 worker 的常驻原子让出标志先于任何 invocation 创建，固定结构大小不包含它的 Arc 分配。公开宿主 token 也可能早于调用创建并在调用结束后存活。不能借调用票据声称这些独立生命周期已计费。

新增 `CancellationToken::new_accounted(account)` 与 `PreemptionToken::new_accounted(account)`。计费标志存储在一次 Arc 分配内，包含原子值和资源票据；分配前向指定账户及祖先预留存储与两份 Arc 引用计数的逻辑字节。clone 只共享，最后一个 token/执行持有者释放才归还，跨线程末 owner 规则相同。拒绝不创建标志、不改变任何账户；不改变 SeqCst、取消不可重置及让出请求合并语义。

私有存储区分计费与外部预付的 Arc 两种表示，后者保留原子的小分配而不内嵌空票据。这样不放大每次默认调用的堆控制存储，原 4352 B 上限同时纳入两次默认标志分配及引用计数的显式尺寸断言；不能通过提高控制额度容纳不必要的空票据。

ScalarWorker 的常驻让出标志使用 tenant 计费构造。Scheduler actor 的取消标志使用自己的 process 计费构造，移除原 actor 控制中的 64 B 合并预付，避免重复计费。Scheduler worker 私有 token 仍由原线程控制预留覆盖，线程退出并 join 后才归还；initializer/调用内部默认 token 仍由原执行核心预留覆盖，CLI 私有取消标志由 adapter 控制预留覆盖。公开 `Default` 保留宿主/工具用法，不表示自行创建的外部 token 已由 VM 计费。

可选观测保留原 4096 B 一次准入，覆盖 observer 和标志，不再对其中标志重复收费；所有公开 token 克隆共同持有 observer 租约。源码 ABI v19、4352 B 执行预留、账户/队列/堆/栈上限及所有 CPU/墙钟/阶段限制不变。固定控制类型的大小回归须覆盖新的共享存储，而不只测 token 指针。

## 验证与边界

验证 process/tenant/VM 不足/精确边界、拒绝零变化、clone 不重收、原账户句柄退出、跨线程末释放与真实执行挂起/取消/返回时的租约。独立回归保留 worker 销毁后存活的私有 token，以复现旧常驻分配无票据；Scheduler 验证停止及外部克隆延长取消标志租约。既有 timer、预算、原子让出、观测、队首准备拒绝与资源净转移回归不放宽。

这仍是逻辑存储准入，不计 allocator 内部元数据，不保证全局 OOM 可恢复。通用记录、其他分配/装载边界、长时公平/过载/故障、最新原生双平台和 BEAM 同负载吞吐/整机内存双门禁保持未完成，不宣布 MVP 完成。
