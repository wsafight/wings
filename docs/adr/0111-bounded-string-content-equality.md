# ADR-0111：分块字符串内容相等比较

- 日期：2026-11-17
- 状态：已采纳（最小业务值能力）
- 延续：[ADR-0103](0103-accounted-utf8-string-values.md) 的独立 UTF-8 类型、分块检查和精确根。
- 部分替代：ADR-0103 暂不支持字符串内容比较的边界；其他引用类型仍不能直接比较。

## 决定

开放 `String == String` 和 `String != String`，返回 Bool，比较完整 UTF-8 编码内容而不是堆引用、长度或固定前缀。同一引用也通过有界受管比较，不提供绕过预算/取消的身份快路径。空字符串相等，嵌入 NUL 正常参与比较；不做 Unicode 规范化、大小写折叠或区域处理，例如 `"é" != "é"`。仍拒绝排序、String/Bytes 或其他类型混合、隐式转换及其他引用的直接比较。

lowering 将两种运算降为专用 Bool IR `EqualStrings`，不允许通用整数 `Compare` 接受引用；`!=` 在 Bool 结果上取反。IR 独立验证两输入均为 StringRef 且输出为 Bool。codegen 走堆回调并为无本地构造的参数比较分配固定 scratch，原始引用身份不外泄。

runtime 校验两个引用的类型与代次，在长度判断前扣预算/检查取消及让出，再每至多 256 字节检查并比较。长度不同或首次内容不同可提前返回；不是常量时间密码比较。每次检查后重新借用/验证对象，不跨可能 GC/让出的调用持有 heap slice。两个最后使用参数由 compiler root plan 保活，GC 可以在任意检查点运行。比较不创建业务对象或 payload，不转移额度；失败不写回调输出，也不提交候选状态。

源码 ABI 升至 v21，新增 heap opcode 21。旧产物必须重编译，context 88 B、EffectRequest 80 B、4352 B 执行控制预留、堆/栈/消息容量和原所有时限不变。不修改待审语法或类型大小写。

实际命令、结果、保留的失败与平台边界见[验证记录](../validation-string-equality-2026-11-17.md)。
