# ADR-0113：具名记录消息的有界字段展开

- 日期：2026-11-17
- 状态：已采纳（消息参数业务值切片）
- 部分替代：[ADR-0108](0108-bounded-named-record-values.md) 暂不开放具名记录消息参数的限制；记录回复仍不开放。

## 决定

允许具名记录作为单向消息和请求参数，覆盖 send_self/send/request。源码仍按名义类型检查，不允许同形异名替代。compiler 将参数按声明顺序深度优先展开为既有 Int/Bool/Unit/RecordInt/IntList/Bytes/String 叶值；目标薄入口在 handler 业务前，以原 schema 构造目标堆独立记录。空记录没有叶值，但仍创建独立目标记录。实参只求值一次，字段读取和构造保留强制检查点及精确根；不发送任何源堆 handle，也不保留共享可变业务数据。

每个源码消息最多 64 个参数；一条消息所有参数展开树的记录节点与叶值合计至多 64，按出现次数计数，不按共享引用去重。该界同时约束空记录和嵌套展开，禁止指数级编译/目标分配。既有全部列表合计 64 整数、String/Bytes 合计 65536 字节、64 个入口根及原堆槽/消息/请求容量不变。超界在 AOT 生成前拒绝，不靠增大运行时控制预留解决。

不改受管 ABI v21、EffectRequest/context 布局或 4352 B 控制预留；清单和 IR 消息签名仍只含既有叶类型，由 IR/清单独立验证。含记录的 handler 在清单使用按位置生成的参数名；可信宿主使用既有 MessageValue 传递展开后的叶值，不新增裸记录 handle 或 JSON 对象入口。标量入口继续拒绝引用叶值，源码 LSP 仍展示具名记录签名。

发布前源暂存、发布时向目标净转移、目标导入计费与入口根完全复用既有复制路径；重建失败不执行业务、不提交 state，不撤回已发布消息或此前副作用。timeout/cancel/Drop 不撤回消息，保持原结果双端租约。记录回复和具名宿主对象 API 单独决策。

## 验证

实际命令、结果、首次失败与平台边界见[验证记录](../validation-named-record-messages-2026-11-17.md)。

验证嵌套/空/混合记录、同形异名拒绝、单次实参求值、64 节点含界/超界、重复子树和现有 byte/list 合计上限。IR 必须不含外部 RecordRef 参数，字段读取和目标构造保留源/目标精确根。真实 AOT 覆盖跨函数/GC/逐片恢复、单/双 worker、语言 request、失败候选副作用、导入失败/超额/停止和清理，原 CPU/墙钟/3 秒阶段不变。
