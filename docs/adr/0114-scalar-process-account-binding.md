# ADR-0114：标量实例的进程账户身份绑定

- 日期：2026-11-17
- 状态：已采纳（资源隔离修正）
- 部分替代：[ADR-0080](0080-central-execution-admission.md) 的显式标量池选择规则及 [ADR-0053](0053-detached-process-images.md) 仅对带堆镜像保留原 process 身份的限制。

## 缺陷与决定

标量实例没有堆账户约束。即使 initializer 已在 process A 的计费池运行，同 VM 的另一个 process B 的池或未计费工具池仍可用于 `start_in_pool`；detach 后也能改绑 B。代码所属 VM 检查不能替代进程身份，宿主可绕开 A 的原限额。

从显式 process 计费池创建的所有实例（含纯标量）保存原 process 账户身份。每次 invocation 在控制预留、借栈、创建 token、移动载荷或业务执行前要求目标池仍属于该账户；同账户可以换池/换线程，不能换到兄弟 process、其他 tenant/VM、未绑定或未计费池。失败不毒化实例、不改 state/账目/池，之后可在正确池重试。

detach 搬运该线程安全账户身份，不携带栈池或活栈；attach 先验证模块 VM、原账户和堆账户，失败不取走镜像。正确账户可重新绑定，成功仅一次，失败实例不因迁移恢复健康。旧未计费工具实例保留无固定账户的显式选池能力，但不据此声称受管隔离；计费模块仍须本 VM 的 process 池。

新增身份只克隆既有 ResourceAccount 租约，不新增账户节点/业务存储；原账户元数据随最后实例/镜像持有者释放。固定结构增加一个可选账户句柄，worker/actor/调用控制按实际类型现有准入覆盖，4352 B 固定控制上界必须继续通过。ABI v21、栈/堆/消息/请求/CPU/墙钟/阶段限制不变。

## 验证

实际命令、旧实现失败、全量结果及平台边界见[验证记录](../validation-scalar-account-binding-2026-11-17.md)。

先用纯标量实例直接换池和 detach 换账户复现旧实现失败，再检查同 VM 兄弟/其他 tenant/跨 VM/工具池拒绝，原账户满额不能借别人的容量，拒绝不触发 token 工厂或借栈。覆盖 ScalarTask、同账户新线程 attach、账户句柄退出和失败镜像；真实 AOT 检查正确池重试/原提交/清理。既有工具示例保持原行为，最新原生双平台及 BEAM 双门禁仍独立验收。
