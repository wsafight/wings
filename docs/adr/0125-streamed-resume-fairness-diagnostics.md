# ADR-0125：持续公平性业务中的恢复区间流

- 日期：2026-11-18
- 状态：已采纳（独立诊断协议，公平性与 MVP 门禁未通过）
- 延续：[ADR-0077](0077-streamed-fairness-measurement.md) 的原业务与阶段、[ADR-0124](0124-bounded-scheduler-slice-observation.md) 的恢复区间来源。
- 部分替代：首轮历史满额的保留与后续 v13 策略见 [ADR-0126](0126-bounded-resume-trace-retention.md)；原 v12 仍在上限处失败。

## 决定

保留原 v7/v8 命令、协议、事件和结果；新增独立 `beam_fairness --trusted ARTIFACT --measure-slices TRACE [--observe]`，输出诊断协议 v12，非 ABI 版本。仍为 101×256 B、单 worker、原 mailbox/pending/总预算、片预算 4096、quantum 1ms；热 actor 连续执行原六层受管函数的百万次 checked 加法，100 个冷 actor 每 10ms 同刻到达心跳，30s 预热/60s 采样，最终收齐并检查全部状态。没有提高片预算或 quantum 来制造原子样本。

启用每 worker 1024 条计费恢复 FIFO，每轮宿主循环最多取 1024 条，以原固定 64 KiB buffer 流式写 40 B 大端记录。新 kind 8/9/10 分别表示 Suspended/Complete/Failed，记录 worker 内序号、恢复开始/返回时间和稳定完整 Pid 映射出的 actor 身份；当前只有一个 worker，不抹去跨 worker 全序缺口。原原子请求 kind 7 保持独立，可显式同时启用。初始化配置也保留，结束后先停止/join，再取完 FIFO 并核对统计。

恢复事件最多 8000000 条，达到上限后使实验失败并保留原始文件；原心跳/热任务/原子让出各自上限不变。独立 v12 文件上限为原 v8 上限加 8000000×40 B，未修改旧协议的上限。沿用 CPU 240s/墙钟 130s/阶段 120s/core 0、原结果/状态/内存探针保护；运行端不保存全部恢复历史。离线验证使用有上限的 packed u64 数组和精确 nearest-rank 分位，处理内存与其开销单独披露，不将它算成 VM 业务堆。

## 独立重放

先沿原 v8 模型核对所有业务事件、完整返回与提交值，再独立核对恢复事件的单 worker 序号、真实区间不重叠、actor 身份、累计丢样与停止统计。时钟相对原观测起点，以已记录的业务偏移区分初始化、预热和采样。完整流的每个 actor 必须恰好有一次 Configure 完成，加上其最终提交计数对应的业务完成；没有业务失败，也不能以遗漏恢复记录伪造完整性。

完整流另以固定上限的 FIFO 将实际恢复逐次对应到已接受的业务请求：不得早于宿主发送时点开始，Complete 不得晚于宿主观察结果；配置完成须在业务起点前。结果观察和区间落盘允许任意先后，只有两者齐备才清理对应项，避免凭文件位置误判。出现缺口后停止该关联并披露已验证前缀，既不猜测丢失的 Complete，也不无界积累后继业务。

仅在某 actor 上次返回为 Suspended 时，记录它到下次恢复开始的等待；已 Complete 后的空闲时间不算可运行等待。跨缺样区间不推断该等待。每 actor 及全局分别报告恢复调用墙钟区间与可恢复等待；按本次开始时点归采样，零样本保持 null。FIFO 丢样时完整性为 false，保留可观察子集与缺口，不能把其分位当作完整分布。原子请求延迟、心跳端到端延迟和这两项诊断不混为一谈。

下一次恢复开始已跨过采样终点时，另报到终点的等待下界，不将该边界样本塞入完整等待分位或静默当作零等待。重放在单独的受限 OS 子进程中执行冻结验证器，验证自身内存未纳入业务采样窗的 VM 指标。

新增独立测量入口固定五次 Wings 诊断运行，冻结源码、可执行文件、AOT、验证器与 probe；不将没有 BEAM 调度内部事件的诊断冒充五对性能对照。旧 v8 仍承担原 Wings/BEAM 业务比较。本切片没有 CPU 硬配额、过载分组、原生双平台或整机内存/吞吐双门禁结论。

## 验证与重审

保留旧 v7/v8 拒绝与正确性回归，新增独立重放模型的伪造序号、区间、结果、身份、计数与截断拒绝，验证有丢样历史和零样本边界；新模式实际执行原 30s/60s 长测，失败不重试、不提高时限。若原始观测扰动使业务拒绝或超时，公开原计数，不删样或改成闭环。

直接把旧 v8 的零原子样本改称步骤片、只看全局分位、删除 FIFO 丢样，都会隐藏不同来源，不采用。以后改变 drain 上限、FIFO 容量、事件上限、阶段或分类口径，重新冻结协议，不回写历史结果。
